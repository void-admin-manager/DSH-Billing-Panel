# 用量与预算面板（usage-balance）

DeepSeek Harness 的 Web 客户端插件：在对话窗**右下角**显示账号余额与本月用量，并把**每一轮回答**消耗的
tokens、金额、时长统计出来；你可以给这三项各设一条上限，超出即自动中止该轮回答。

一句话：**看得到这一轮花了多少，也拦得住它继续花。**

---

## 功能

**1. 账号概览（右下角面板）**

- 余额：充值余额与赠送余额，以及账号状态。
- 本月用量：按天的消费曲线与合计（走 Platform 用量接口，只读）。
- 每分钟自动刷新一次；面板上有一个手动刷新入口。

**2. 每轮回答的统计**

「一轮」= 你发出一次提问到这次回答结束（`turn/start` → `turn/end`），**这一轮里发出的每一次模型请求都累加在一起**，
不是只算最后一次请求。

| 读数 | 含义 |
|---|---|
| tokens | 本轮所有请求的输入 + 输出总量；输入再按「缓存命中 / 缓存未命中 / 缓存写入」拆开显示 |
| 消费 | 按官方价目表逐次请求计价后的估算金额（元） |
| 时长 | 本轮从开始到结束的实际秒数，回答进行中每秒跳动 |
| 请求数 | 本轮发出的请求次数 |

**3. 三条可编辑上限**

| 上限 | 单位 | 可设范围 | 默认 |
|---|---|---|---|
| tokens | 万tokens | `1` – `210000`（即 1 万 – 21 亿 tokens） | `10000`（= 1 亿） |
| 消费 | 元 | `1` – `100000` | `5` |
| 时长 | 秒 | `60` – `86400`（24 小时） | `3600` |

任一条被突破时：立刻中止本轮回答 → 在同一会话里排队一条简短说明（写明是哪条上限、实际用量与上限值，
并请模型用不超过 500 tokens 收尾），说明本身也受同样的上限约束。**同一轮不会被中止两次。**

**4. 其它**

- **手动中止**：`■` 按钮，用与自动中止同一条路径停掉正在进行的回答，并如实回报结果（被拒绝时不会谎报「已中止」）。
- **子代理计入**：一轮里派出的子代理（subagent）所消耗的 tokens、金额与请求数**并入这一轮**；时长仍只按主回答计。
- **台账**：每轮结束写一行 JSON 到 `log/turns.jsonl`，含该轮 tokens 拆分、金额与其构成、时长、请求数、当时生效的上限。
- **本地价目**：每天读取一次官方价目页并写入 `pricing.json`；读不到就用本地那份；本地也没有就用内置的官方人民币价。
- **中英文双语**：跟随界面语言。

## 使用方法

**安装位置**

把本目录放在 Harness 的插件源目录下（`~/.dsh/plugin-src/<目录名>`）。宿主半边随 Harness 启动加载，
浏览器半边由 Harness 作为 web 插件提供给页面。

**面板何时出现**

在对话窗右下角，需要窗口/分栏足够宽（宽 ≥ 1440px、高 ≥ 256px）才显示；窗口太小时自动隐藏，变宽后自动出现。

**改上限**

- 直接点数字所在的输入框改，**回车或移到别处**即生效并记住（下次打开还是这个值）。
- 三个输入框都有各自的范围（见上表），超出会被夹回范围内；**清空再离开会保留原值**，不会掉到最小值。
- 回答进行中，三个输入框与总开关会锁定（显示「回答进行中，上限已锁定」），这一轮结束后自动解锁。
- 想整体关掉上限判定，取消左上角勾选框即可（统计照常，只是不再中止）。

**中止回答**

点 `■` 按钮。回答中可点；空闲时按钮禁用。中止只作用于当前会话的当前回答（见「注意事项」第 4 条）。

**数据文件**

| 文件 | 内容 | 位置 |
|---|---|---|
| `log/turns.jsonl` | 每轮回答一行 JSON：`schema`、`writtenAt`、`sessionId`、`turn`、`endedAt`、`tokens`、`input` / `uncachedInput` / `cacheRead` / `cacheWrite` / `output`、`cost`、`costParts`、`currency`、`seconds`、`requests`、`ownRequests`、`ownTokens`、`subagents`、`model`、`stopped`、`reason`、`limits` | 默认本插件目录下 `log/`；`DSH_USAGE_BALANCE_LEDGER` 可改成任意路径 |
| `pricing.json` | 官方两版价目表的**原文金额**（`published.zh` 元 / `published.en` 美元）＋ 供计价用的折算表 `table`（元/百万 tokens）、`writtenAt`、`primary` | 默认本插件目录下 `pricing.json`；`DSH_USAGE_BALANCE_PRICING` 可改成任意路径 |

两个文件都是纯本地文件，只有数字、ID 与模型名，**不含对话内容、不含任何凭据**。

**需要重启的情况**

改动 `lib/index.js`（宿主半边）后需要重启一次 Harness 才生效；`lib/client.js`（浏览器半边）改动刷新页面即可。

## 注意事项

**1. 没有节假日表 —— 中国法定节假日期间，本插件的消费估算会明显高于官方统计**

官方规则是「**北京时间周一至周五（不含中国法定节假日）** 9:00–12:00、14:00–18:00 为高峰时段，
其余时段（含周末与法定节假日全天）为空闲时段」，空闲价是高峰价的一半。
本插件**只按星期判断高峰时段，没有节假日表**，所以：

- 法定节假日如果落在周一至周五：那两个时段官方按**空闲价**计，本插件按**高峰价**计 → **估算最高偏高约 1 倍**；
- 周末与调休上班的周末：官方按空闲价计，本插件同样按空闲价计 → 一致。

也就是说，**节假日期间（尤其春节、国庆这类长假）请以官方账单为准**，本插件的数字会偏高。
这不是可以顺手修掉的小问题：节假日日期无法从星期推算（春节、端午、中秋按农历，清明按节气，
调休还需国务院逐年公布），离线只能靠一张**每年维护**的节假日表，联网抓取则会在来源不可达时完全失效。
本插件的取舍是：**宁可少一个特性，也不引入会失效的外部依赖**，因此保留该偏差并在中英文 README 中说明。

**2. 面板上的金额是估算，不是账单**

- provider 没有上报用量的请求无法计入；
- 会话标题、摘要等由 Harness 自行发起的模型请求不产生用量事件，因此不在统计内；
- 模型路由无法识别时按 `deepseek-flash` 的价目计价；
- 对账请以官网/平台的账单为准，本插件的数字用于**实时看趋势与设预算**。

**3. 价目来源与降级**

- 官方**没有**机器可读的定价接口，只有两个文档页（中文页人民币价、英文页美元价），本插件每天读一次中文页
  并按原值使用人民币金额；中文页读不到时才回落英文页，并按固定汇率折算（**这一路是近似值**：官方两版价目并不成比例）。
- 读不到页面时使用本地 `pricing.json`；连它也没有或不合法时，使用内置的官方人民币价 —— **离线也能正确计价**。
- 公开文档页改版会导致解析失败，此时同样按上面的顺序降级，不会算错价，只是可能暂时用的是上一份价目。

**4. 中止回答的边界**

- 中止只停**当前会话的当前回答**；
- 该轮若已派出**在后台继续运行**的子代理（可续跑型），它们**不会**跟着停止 —— 这是 Harness 的接口行为：
  这类子代理的调用早已返回，只有整个会话停止/归档时才会被一并取消；
- 已经运行完的请求无法「撤销」，中止只是让这一轮不再继续发新请求。

**5. 其它**

- 三条上限是**预算上限**，本身不产生任何扣费，只决定何时中止回答。
- 面板的余额与月度用量走的是 Platform **私有**用量接口；该接口若变更，这两项可能显示为暂不可用，
  但按轮统计、上限判定与台账不受影响。
- 时长上限按事件时间计算，只统计主回答，不含子代理的运行时间。

## 文件构成

| 文件 | 作用 |
|---|---|
| `package.json` | 包声明：`dsh.client` 段声明这是 web 客户端插件，`exports["./client"]` 指向浏览器半边 |
| `lib/index.js` | 宿主半边：读取账号凭据、请求 Platform 用量、每天读取并缓存价目表、注册三条回环 JSON 路由（用量 / 价目 / 台账）、把端点注入页面 |
| `lib/client.js` | 浏览器半边：渲染面板、按轮累加用量、执行三条上限、每轮结束把该轮写入台账 |
| `README.md` / `README.zh.md` | 本说明（英文 / 中文） |
| `log/turns.jsonl` | 运行时生成：每轮回答一行台账 |
| `pricing.json` | 运行时生成：本地价目表（读到页面时每天更新一次） |

运行时依赖：Harness 自带的 Node（24 及以上）与 Electron/Web 环境；无第三方依赖，无需编译。
